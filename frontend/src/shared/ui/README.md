# UI dùng chung

Thư mục dành cho các component được nhiều trang sử dụng, ví dụ `Button`, `FormField`, `PasswordField`, `Card` và thông báo trạng thái.

- Component ở đây nhận dữ liệu qua props và không chứa logic gọi API của từng feature.
- Layout toàn ứng dụng nằm trong `src/app/layouts/`.
- Component chỉ dùng trong một chức năng nên đặt cùng feature đó.
- Chỉ thêm component khi bắt đầu sử dụng; FE-02.2 chưa triển khai UI.

File README này giúp thư mục được lưu cùng mã nguồn khi tạo commit sau này.
